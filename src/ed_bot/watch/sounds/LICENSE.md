# Watch Sound Files

These are placeholder sounds generated by `generate.py` using only Python's
stdlib. They are CC0 / public-domain because they're purely procedurally
generated tones with no human creative input.

Replace any or all of these with real CC0 / public-domain audio (e.g., from
freesound.org) by overwriting the .wav files in this directory.

| File | Sound |
|---|---|
| `new.wav` | Single 440 Hz "ding" (200 ms) |
| `followup.wav` | Ascending two-tone 523→659 Hz (300 ms total) |
| `escalation.wav` | Descending three-tone square wave 880→659→440 Hz (360 ms total) |
| `error.wav` | Low 220 Hz square-wave buzz (400 ms) |

To regenerate after editing `generate.py`:

```
cd src/ed_bot/watch/sounds && python generate.py
```
